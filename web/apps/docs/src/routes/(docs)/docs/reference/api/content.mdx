This page is the operator-facing index to Plexor's REST API. It is
hand-curated in the current release; auto-generation from the
source code's route attributes ships in a later release.

The API lives at `https://<your-plexor-host>/api/v1/...`. Every
request requires an `Authorization: Bearer kid_<id>.<secret>`
header (or a session cookie if you signed in through the console).

## Endpoint groups

a Plexor module; the URL path's first segment is the group name.

## Common shapes

A few shapes appear across many endpoints:

### Scope selector

Most endpoints accept a folder scope as query parameters:

```
?scope=org|team|folder&id=<uuid>
```

The `scope` value names the kind; the `id` is the matching entity
id. The platform filters the response to the matching scope.

### Pagination

List endpoints return a cursor-paginated payload:

```json
{
  "items": [...],
  "nextCursor": "<opaque-string>"
}
```

Pass the `cursor` query parameter to fetch the next page. The
default page size is 50; the maximum is 200.

### Timestamps

Every timestamp is **UTC unix milliseconds** (`long`). The wire
format is the long integer, never an ISO string. The platform
converts to `DateTimeOffset` on the server side.

### ID format

Every entity id is a UUID v7. UUID v7 is time-sortable, so range
queries on `Id` give insertion order without a separate
`created_at` index.

## Stable error codes

Every error response is RFC 9457 problem-details JSON. The `code`
field carries a stable dot.case identifier; clients branch on
`code`, never on `message`.

| Code | Meaning |
|---|---|
| `identity.credentials.invalid` | Wrong email or password. |
| `identity.credentials.locked` | Account is locked. |
| `identity.credentials.provider_mismatch` | Wrong auth flow for the tenant's provider. |
| `identity.token.expired` | JWT `exp` is in the past. |
| `identity.token.replay_detected` | Refresh-token reuse; family revoked. |
| `identity.permission.denied` | Permission check failed (HTTP 403). |
| `quotas.exceeded` | Quota walker returned Denied (HTTP 429). |
| `compute.workload.invalid_transition` | State-machine rejected a transition. |
| `validation.failed` | Request body failed validation (HTTP 400). |

The full catalog is in the source code's `ProviderException`
subclasses; this list is the operator-facing subset.
