The recipes in this chapter cover the operations operators run
most often against a live Plexor installation: workloads, storage,
networking, identity, and SSH keys.

## Compute

- [Create a workload](/docs/how-to/create-workload/) — provision a VM or container on a compute node.
- [Workload lifecycle](/docs/how-to/manage-workload-lifecycle/) — start, stop, snapshot, migrate.
- [Attach a volume](/docs/how-to/attach-volume/) — add a block device to an existing workload.

## Storage

- [Create a bucket](/docs/how-to/create-bucket/) — S3-compatible object storage for tenant data.

## Networking

- [Reserve a floating IP](/docs/how-to/reserve-floating-ip/) — bind a public IP to a workload.
- [Add a load balancer](/docs/how-to/add-load-balancer/) — distribute traffic across workloads.

## Identity and access

- [Add a user and assign a role](/docs/how-to/add-user-and-role/) — RBAC for a new operator.
- [Issue an API key](/docs/how-to/issue-api-key/) — programmatic access for CI / scripts.
- [Configure OIDC](/docs/how-to/configure-oidc/) — federate identity through your IdP.
- [Rotate an SSH key](/docs/how-to/rotate-ssh-key/) — credential rotation without downtime.
