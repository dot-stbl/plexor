The bootable ISO is the recommended install path for dedicated
hardware. The image is a small, purpose-built Linux that boots into a
minimal environment, runs the installer wizard, and reboots into a
hardened Plexor appliance.

<Callout type="info">

The full ISO procedure (where to download, how to flash, the wizard
screens in order) is being written up. Until then, the universal
install flow on [Install Plexor](/docs/getting-started/install/) walks
through every step on either install path, and the same five wizard
questions the ISO walks.

</Callout>

## What you need

- One physical server (or a VM with nested virtualisation enabled if
  you want to evaluate on top of a hypervisor you already have).
- A bootable medium: USB stick, or virtual CD-ROM if you are running
  inside another hypervisor.
- Network access from the host to at least one DNS resolver and one
  NTP source. Plexor does not phone home — but its TLS certificates
  and audit-log timestamps require accurate time.
- One free IPv4 address on a network the operator's laptop can reach.
