`plx init` is the install path for development, evaluation, or
hosts where Plexor has to coexist with other software. The CLI
installs the `Plexor.Host` systemd unit, lays down the data
directory, and walks the same wizard as the ISO — minus the
partitioning step.

<Callout type="info">

The full `plx init` procedure (the package mirror, the four
commands, what the wizard does and does not configure) is being
written up. Until then, the universal install flow on [Install
Plexor](/docs/getting-started/install/) covers every step on either
install path, including the `plx init` recipe.

</Callout>

## Prerequisites

- Linux host with kernel 5.15 or newer (`uname -r`).
- systemd (most modern distributions).
- An unused data directory on an XFS or or ext4 filesystem. Plexor
  does not support running its database on btrfs or ZFS in this
  release.
- One unprivileged user account that the installer can use to run
  the host process.
- Outbound HTTPS to the package mirror you are installing from.
