The admin guide covers what an operator does **after** Plexor is
installed and running: monitoring, upgrades, backups, security
hardening, lockout recovery, and the daily operations of keeping
the cluster healthy.

## Day-to-day

- [Reading the audit log](/docs/admin/audit-log/) — every mutating action lands here.
- [Managing quotas](/docs/admin/quotas/) — per-tenant and per-project limits.
- [Capacity planning](/docs/admin/capacity-planning/) — when to add compute nodes or storage.

## Hardening

- [RBAC hardening](/docs/admin/rbac-hardening/) — least-privilege role design.
- [Lockout recovery](/docs/admin/lockout-recovery/) — when an admin is locked out.

## Resilience

- [Backup and disaster avoidance](/docs/admin/backup-and-disaster/) — what to snapshot, where to store, how to restore.
