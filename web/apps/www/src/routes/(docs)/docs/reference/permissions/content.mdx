Every permission in Plexor is a flat string of the form
`<service>.<resource>.<action>[.<qualifier>]`. There are no
wildcards except the `*` super-admin role. This page is the
operator-facing catalog of every string the platform ships.

The catalog is hand-curated in the current release; auto-generation
from the source code's `[RequirePermission]` attributes ships in a
later release.

## Built-in role assignments

The four built-in roles ship with these permission sets:

| Role | Permissions |
|---|---|
| `*` (super-admin) | Every permission, including future ones. |
| `admin` | Every permission except `*`-wildcard-only paths. |
| `operator` | All read permissions, write permissions for compute / storage / network resources. No quota assignment, no role binding edits. |
| `viewer` | All read permissions only. |

The built-in roles are immutable — you cannot add or remove
permissions from them. To customise, create a new role with the
desired permissions and bind it instead.
