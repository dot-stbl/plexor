# Routing — `@plexor/www`

How a URL becomes a rendered component. TanStack Router 1.91, file-based
routes under `src/routes/`. Pathless groups in parentheses
(`(marketing)`, `(docs)`) do not contribute to the URL.

## Diagram

```mermaid
flowchart TD
    URL[/user hits URL/] --> Boot[index.html boot script:<br/>apply preset to data-theme]
    Boot --> Mount[main.tsx<br/>applyBootPreset]
    Mount --> Root{createRouter<br/>routeTree}
    Root -->|path matches /| MGroup[/marketing route.tsx/]
    Root -->|path matches /docs/*| DGroup[/docs route.tsx/]
    Root -->|no match| Router404[DocsNotFound<br/>defaultNotFoundComponent]

    subgraph Marketing[/marketing group/]
      MGroup --> MHdr[MarketingHeader]
      MGroup --> MMain[Outlet -> Landing<br/>Hero/Features/Manifesto/Roadmap/Cta]
      MGroup --> MFtr[MarketingFooter]
    end

    subgraph Docs[/docs group - sidebar+TOC chrome/]
      DGroup --> DHdr[DocsHeader<br/>PlexorMark + Breadcrumb + ThemePickerButton]
      DGroup --> DSide[DocsSidebar<br/>CHAPTERS from docs-sidebar.tsx]
      DGroup --> DMain[Outlet -> page]
      DGroup --> DToc[DocsToc<br/>scrapes h2/h3 from article]
      DGroup --> DFtr[DocsFooter]
      DGroup -->|no match| Docs404[DocsNotFound<br/>notFoundComponent]

      DRedirect[/docs index.tsx<br/>beforeLoad -> redirect/] -.->|/docs or /docs/| DGroup
      DRedirect -->|throw redirect| GettingStarted[/docs/getting-started/]
    end

    Page[/docs/&lt;chapter&gt;/&lt;slug&gt;/index.tsx<br/>+ content.mdx/] -.-> DMain
```

## Per-arrow explanation

- **URL → boot → main.tsx**: every URL serves `index.html` (SPA). The
  inline boot script stamps the persisted theme before any module
  loads (no FOUC). `main.tsx` then calls `applyBootPreset()` for the
  full token set, mounts `<RouterProvider>`.
- **createRouter / routeTree**: matches URL → route id from
  `src/routeTree.gen.ts` (auto-generated by `@tanstack/router-cli`).
- **`/` → `(marketing)/route.tsx`**: pathless group, owns landing
  chrome (header + `<Outlet/>` + footer). Renders `<Landing />` from
  `(marketing)/index.tsx` — five composed marketing sections.
- **`/docs/*` → `(docs)/route.tsx`**: pathless group, owns the docs
  chrome (header + sidebar + `<Outlet/>` + TOC + footer).
- **`/docs` or `/docs/` → redirect**: `(docs)/docs/index.tsx` matches
  the bare prefix; `beforeLoad` throws `redirect()` to
  `/docs/getting-started` **before the component mounts** (no flash).
- **Page → DMain**: each
  `src/routes/(docs)/docs/<chapter>/<slug>/index.tsx` is a thin page
  wrapper that renders `content.mdx`. Register the slug in `CHAPTERS`
  in `src/components/docs/docs-sidebar.tsx` so the sidebar surfaces it.
- **404 — unmatched URL anywhere**: `defaultNotFoundComponent: DocsNotFound`
  in `createRouter(...)`. Centered, two CTAs.
- **404 — unmatched `/docs/*`**: `notFoundComponent: DocsNotFound` on
  `/(docs)` keeps the docs chrome (sidebar/header/TOC) instead of
  falling back to the bare router-level 404.
